6 · Safeguards

Six protections written into the term sheet

  • Tranches on verified gates

    Four ₹45 Cr releases. An independent Scientific Advisory Board confirms each gate before funds move.

  • 1x liquidation preference

    CCPS rank ahead of common. A ₹6,000 Cr partial exit still returns capital.

  • Earned price option

    Step the price ₹3,000 / 4,500 / 6,000 / 6,000 Cr, or reset it if a gate is missed.

  • Reserved matters

    Investor consent to sell or license core IP, new shares, related-party deals and budget overruns above 10%.

  • IP held and escrowed

    All IP assigned to the company. Specification and code held with an independent agent.

  • Quarterly Truthiness report

    Every claim, its state and its falsifier, updated each quarter and sent to investors.

Proposed terms. Counsel to settle all of them.
